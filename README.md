# 수원 똑버스 도입 효과 분석 (DiD)

경기도 DRT(수요응답형 버스) **똑버스** 도입이 지역 대중교통 통행에 어떤 변화를 가져왔는지 분석하는 프로젝트입니다.
수원시 똑버스 01~04번 노선이 서로 다른 시점에 도입된 점을 활용해, 운행 구역(처치군)과 비운행 구역(비교군)의 통행량 변화를 **이중차분(Difference-in-Differences)** 으로 비교합니다.

> 교통 데이터 분석 공모전 출품용 프로젝트이며, 현재 데이터 수집과 사전 검증 단계입니다.

## 데이터 출처

| 출처 | 용도 |
|---|---|
| [STCIS 교통카드 빅데이터 Open API](https://www.stcis.go.kr) | 읍면동 단위 15분 OD, 노선·정류장 정보 |
| [TAGO 국가대중교통정보센터 API](https://www.data.go.kr) | 정류장 좌표 보완 |
| 경기데이터드림 | 수원시 법정동·행정동 매핑 |

API 사양과 실제 호출해 보며 확인한 사항은 [`docs/api_spec.md`](docs/api_spec.md)에 정리했습니다.

## 분석 설계

똑버스는 DRT라서 STCIS에 노선마다 기점·종점 2개 지점만 등록되어 있습니다. 실제 정류장 네트워크를 재구성할 수 없기 때문에, 노선별 **운행 구역을 법정동 단위로 정의**하고 그 구역의 OD 통행량을 분석 단위로 씁니다.

| 노선 | 운행 구역(법정동) |
|---|---|
| 수원똑버스01 (광교) | 이의동, 하동, 상광교동, 하광교동 |
| 수원똑버스02 | 평동, 고색동, 오목천동 |
| 수원똑버스03 | 금곡동, 당수동, 입북동 |
| 수원똑버스04 | 권선동, 곡반정동 |

비교군은 똑버스가 다니지 않는 장안구 정자동 일대입니다.

| 파일 | 설명 |

## 실행 방법

```bash
pip install -r requirements.txt
```

프로젝트 루트에 `.env` 파일을 만들고 API 키를 넣습니다.

```
STCIS_API_KEY=발급받은_키
TAGO_API_KEY=발급받은_키
```

```bash
python src/verify_od_zone_test.py
```

Windows PowerShell에서 한글 출력이 깨지면 먼저 `$env:PYTHONIOENCODING='utf-8'`를 실행하세요.

### STCIS API 호출 시 주의사항

- 요청에 브라우저 `User-Agent` 헤더가 없으면 서버가 응답하지 않고 타임아웃됩니다.
- 짧은 시간에 40~60건 정도 연속으로 호출하면 API 호스트가 일정 시간 연결을 막습니다. 공식 문서에는 없는 제한입니다. 그래서 수집 스크립트는 호출 사이에 대기 시간을 두고, 받은 결과를 바로 CSV에 저장해 다시 실행하면 이어서 받도록 만들었습니다.
- 15분단위 OD(`quarterod`)는 도착 읍면동 코드를 생략할 수 없어서, 도착 동마다 따로 호출해야 합니다.
