# 기관 문의 초안 — 미발송

아래는 연구 목적의 질문 초안이다. 실제 수신 채널과 담당 부서는 공식 홈페이지에서 확인한 뒤 작성자가 발송한다. 답변 전에는 보고서에서 '확인했다', '문의 결과'라고 쓰지 않는다.

## STCIS 운영기관: DRT 집계 정의 확인

제목: 수원 똑버스의 노선별 이용량 및 읍면동 O/D 집계 기준 확인 요청

안녕하세요. 교통 데이터 분석 공모전에서 수원 똑버스의 공개 통계를 분석하고 있습니다. 노선별 이용량과 읍면동 O/D가 동일 통행을 어떤 단위로 집계하는지 확인하고자 아래 사항을 문의드립니다.

1. 수원똑버스 01~04가 노선별 이용량, 이용객수요(O/D), 정류장별 이용량 각각에 포함되는지, 최초 수록 시점과 소급 갱신 여부를 알려주실 수 있을까요? 01번의 최초 수록이 2024년 4월이라는 기존 관찰도 공식적으로 확인하고 싶습니다.
2. 노선별 이용량과 O/D의 통행은 승차 건, 환승 구간, 환승을 연결한 전체 여정 중 어느 단위인가요? DRT와 일반 버스·전철을 연계한 여정은 어떻게 처리되나요?
3. 가상정류장 승하차 좌표는 출발·도착 읍면동에 어떻게 귀속되나요? 법정동/행정동, 행정구역 변경, 좌표 미매칭 처리 규칙도 확인 부탁드립니다.
4. O/D의 통행거리는 개별 통행의 평균인지, 경로 추정값인지요? 쌍이 자료에 나타나지 않을 때 실제 0건인지, 비공개·미관측·결측인지 구분할 수 있나요? 소량 집계 비공개 기준이 있다면 알려주세요.
5. 내려받은 파일의 합계·이용자유형·월별 집계 기준과 통계 정의 문서의 공식 URL이 있다면 공유 부탁드립니다.

자료의 미반영을 전제하는 문의가 아니라, 통계 간 비교 가능성을 확인하기 위한 요청입니다. 분석 코드: https://github.com/hj031221/traffic-analysis . 감사합니다.

## 경기교통공사·수원시: 운영 및 대체수단 자료

제목: 수원 똑버스 이동권·탄소 평가를 위한 비식별 운영 집계 확인 요청

안녕하세요. 수원 똑버스의 이용 패턴과 평가 체계를 연구하고 있습니다. 개인 식별 자료 없이 아래 운영 정보의 확인 또는 공개 가능 여부를 문의드립니다.

1. 01~04 노선의 실제 운영 구역, 시범/정식 개통일, 운행 시간·차량 투입 변경 이력, 현 차량별 차종·연료/전기 여부
2. 월·노선별 연료(L) 또는 전력(kWh), 총 차량km, 공차km, 승객 탑승 차량km, 탑승 여객km, 출발-도착 직결 여객km
3. 평균 재차인원의 산식: 시간 가중/거리 가중 여부, 공차 포함 여부, 시간대·요일별 값
4. 호출·배차 성공·미배차·취소 건수, 대기시간과 우회시간 분포, 일반·청소년·고령자 등 비식별 집계
5. 해당 DRT 통행이 없었다면 이용했을 수단, 보호자 전용 왕복 여부, 신규 통행 여부를 조사한 통행단위 설문이나 수단전환 평가가 있는지
6. 기존 수원시정연구원 설문 이후 조사 또는 공개 보고서가 있는지, 통계 공개에 필요한 최소 집계·비식별 기준

탄소 모델에서 공차율은 공차km/탑승 차량km, 재차인원은 공차 제외 거리 가중값으로 정의하고 있으므로 기관의 기존 산식과 차이도 알려주시면 감사하겠습니다.

## 답변 반영 원칙

기관·일자·문서 URL·질문별 답변을 기록한다. 포함 여부가 확인되면 연구의 식별 가능성을 다시 평가한다. 운행 조건 실측은 시나리오 가정을 대체하되 단위가 같을 때만 적용한다. 답변이 없으면 현 보고서의 '확인 필요' 문구를 유지한다.
