# 양식에 옮길 때 — 제출 문안 외 작업 메모

`submission_report.md`의 이름/팀명을 실제 값으로 바꾸고 공식 양식의 같은 항목에 복사한다. 본문 5장 내외(표지·참고문헌 제외)를 목표로 쓴 문안이며 실제 페이지 수는 한글/워드의 글자 크기·행간·표 여백에 따라 확인해야 한다. 링크는 PDF에서도 클릭되는지 점검한다.

권장 배치: 1쪽 배경·데이터, 2쪽 방법·AI 활용, 3쪽 이용 결과와 그림 1, 4쪽 거리 민감도·조회 공백과 그림 2·3, 5쪽 탄소 결과·정책 및 그림 4. 참고문헌은 본문 뒤에 배치한다. 각 필수 항목의 제목은 유지한다. 그림을 결과 옆에 배치하면 맨 뒤에 같은 그림을 중복 삽입할 필요는 없다. '분석결과 이미지(필수)'에는 그림 1~4가 본문에 포함됐음을 명시한다.

그림은 원본 PNG를 삽입하고 캡션과 함께 같은 페이지에 둔다. 표의 한 행이 페이지 사이에 갈라지지 않게 설정한다. 기본 제목 'Untitled', raw LaTeX 명령, 임시 코멘트는 최종 PDF에 남기지 않는다. 권장 파일명: `이름또는팀명_분석보고서.pdf`.

확인 전 남은 외부 사항: 기관 문의 미발송·운영 조건 미실측, 작성자의 최종 문구 확인. 이를 확인했다는 표현을 추가하지 않는다. 본문은 현재 관측 결과와 한계만으로 제출할 수 있도록 작성했다. 기관 답변이 오면 해당 항목에 출처·일자를 붙여 수정한다.
